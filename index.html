틈영단 조종 매뉴얼 및 기능 명세

1. Gemini AI 자동 단어장 구축

원하는 교과서 단원이나 영어 주제를 입력하면 Gemini API가 실시간으로 발음기호, 한국어 뜻, 활용 예문을 구조화하여 단어장에 자동 수집합니다.

2. Web Speech API 기반 STT 발음 사격

사격 훈련소 3번 모드에서는 웹 브라우저 마이크를 통해 직접 영단어를 정확히 발음해야 정답 처리되는 음성 인식 시스템을 제공합니다.

3. 워프 몰입실 (Page Visibility API)

공부 도중 유튜브나 인스타그램 등 다른 탭으로 이동 시 즉시 감지하여 사이렌 알람이 울리며 몰입 유지를 강제합니다.

1. 개발 배경 및 목적

학생들이 영어 단어 암기 시 지루함을 느끼고 스마트폰/웹 딴짓(유튜브, SNS)으로 집중력이 흐려지는 문제를 해결하기 위해, **우주선 콕핏 테마의 게이미피케이션**과 **AI 단어 생성 + 방해 차단 알람**을 결합하였습니다.

2. 사용된 핵심 웹 표준 기술

  • Google Gemini AI API: 교과서 단원 기반 영단어 자동 구조화 생성
  • Web Speech API (STT/TTS): 마이크 음성인식 사격 퀴즈 및 원어민 발음 재생
  • Page Visibility API: 탭 이탈 시 실시간 이탈 감지 및 비상 사이렌 경보
  • Web Audio API: 외부 음원 없이 순수 코드로 SF 비프음/경보음 신디사이저 구현
